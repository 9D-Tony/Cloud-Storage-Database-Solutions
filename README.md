# Cloud Storage Database Solutions
A list of some interesting cloud storage and database solutions.

## [Bunny.net](Bunny.net)

Has database and storage solutions for a minimum of $1/month for storage solutions.

## [Cloudflare](https://www.cloudflare.com)

has database and storage solutions with a free tier.

## [Supabase](https://supabase.com)

Has database and storage solutions with a free tier.

## [Turso](https://turso.tech/)

has database solutions with a free tier.

## [Upstash](https://upstash.com/)

Has redis in memory key-value store for low latency. Has a free tier.
